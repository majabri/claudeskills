## Waterfall 5-Phase Lifecycle
| Phase | Purpose | Key Outputs |
|---|---|---|
| Initiating | Authorize project | Project Charter, Stakeholder Register |
| Planning | Define how | Project Management Plan |
| Executing | Do the work | Deliverables, issue log |
| Monitoring & Controlling | Track and regulate | Performance reports, change requests |
| Closing | Formally close | Final report, lessons learned |

## Earned Value Management (EVM)
PV = Planned Value | EV = Earned Value | AC = Actual Cost | BAC = Budget at Completion

| Formula | Meaning |
|---|---|
| CV = EV – AC | Negative = over budget |
| SV = EV – PV | Negative = behind schedule |
| CPI = EV / AC | <1 = over budget |
| SPI = EV / PV | <1 = behind schedule |
| EAC = BAC / CPI | Forecast total cost |

## Critical Path Method
Critical path = longest dependent task sequence. Float = 0 on critical tasks.
Steps: list tasks + durations + dependencies → forward pass (ES/EF) → backward pass (LS/LF) → Float = LS – ES → Float=0 tasks = critical path

## Waterfall Failure Modes
- Requirements change after sign-off → discovery phase; staged sign-off
- No working software until end → integration milestones
- Risks discovered late → monthly risk reviews with named owners
