# PM L0 — Execute & Operate

Daily execution tier. Altitude: a single sprint, standup, meeting, task, or immediate blocker.

## What belongs at L0

- **Daily standups**: Facilitating, diagnosing anti-patterns, writing agendas
- **Sprint operations**: Sprint goal creation, board hygiene, burndown tracking, review prep
- **Kanban flow**: WIP limit enforcement, cycle time monitoring, blocked-card triage
- **Status reporting**: RAG status (Red/Amber/Green), executive summaries
- **Blockers**: Diagnosing why a task is stuck, escalation path
- **Meeting facilitation**: Agendas, timeboxing, DACI decisions, action item capture
- **Retrospectives**: Start/Stop/Continue, 4Ls, Mad/Sad/Glad, sailboat formats
- **Delivery tracking**: Milestone check-ins, velocity, throughput

## Status Report Formula

```
Summary (1-2 sentences): Overall health (RAG)
Accomplishments: What shipped or progressed?
Next period: What's the plan?
Risks/Issues: What needs attention?
Decisions needed: What must stakeholders decide?
```

## Retrospective Steps

1. Set the stage (5 min): Prime directive, psychological safety
2. Gather data (10 min): What happened?
3. Generate insights (10 min): Why? Root causes?
4. Decide actions (10 min): Pick 1–3 improvements with owners
5. Close (5 min): Appreciation, confirm action owners

## Sprint Health Signals

- Burndown flat mid-sprint → scope creep or underestimate; inspect now
- Velocity volatile >30% → estimation or instability problem
- Stories rolling over repeatedly → DoD issue or external dependency
- Sprint goal ignored → separate goal from story list; make it visible

## Escalate to L1 when

Execution problem reveals a planning gap (no scope, missing stakeholder alignment, no milestones).
